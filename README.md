# 🚕 Taxi Park Management System — UI/UX Case & Design System
Командный UI/UX проект по проектированию адаптивного веб-интерфейса и мобильного приложения для системы управления таксопарком.
## 📐 Особенности проекта
**Командная разработка:** Проект реализован командой из 3 UI/UX дизайнеров.
**Адаптивность (Responsive Design):** Проработаны полноценные макеты для 3 типов устройств:
📱 **Mobile** (версия для смартфонов)
📱 **Tablet** (версия для планшетов)
💻 **Laptop / Desktop** (полноразмерная веб-версия)
**Архитектура и сценарии (User Flow):** Построена карта экранов и информационная структура системы (Site Map).
 **Дизайн-система:** Единый стильный контрастный интерфейс (Dark/Yellow theme), компонентная база и сетки.
## 🎨 Основной функционал и экраны
- Авторизация, регистрация и восстановление доступа.
- Интерактивная карта и отслеживание автомобилей/водителей.
- Панель управления таксопарком (Dashboard) и аналитика.
- Профиль пользователя, тарифы и настройки.
